One-time setup on this device

This page saves sold-out changes straight to your GitHub menu. It needs an access key that can only change this one menu.

  1. On this device, open GitHub → New fine-grained token (sign in as brytoncafbiz-ui).
  2. Token name: Bryton sold-out switch
  3. Expiration: choose the longest option offered (e.g. 1 year). Note the date; you'll repeat these steps after it expires.
  4. Repository access: Only select repositories → pick bryton-menu.
  5. Permissions → Repository permissions → Contents: set to Read and write. Leave everything else as is.
  6. Tap Generate token, then copy it (starts with github_pat_). GitHub shows it only once.
  7. Paste it below and tap Save key.
Advanced (only if your repository name is different)

The key is stored only in this browser on this device. Don't share it. If a device is lost, delete the token on GitHub (Settings → Developer settings → Personal access tokens).
